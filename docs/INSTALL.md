# راهنمای نصب و راه‌اندازی

## پیش‌نیاز
وردپرس ۶٫۵+، PHP ۸٫۰+ (با gd یا imagick)، HTTPS. میزبانی داخل ایران و CDN داخلی پیشنهاد می‌شود.

## گام‌ها
1. **نصب قالب و افزونه‌ها** (ترتیب: Core، E-Services، Khesht Builder، سپس قالب خشت).
2. **زبان**: «تنظیمات ← عمومی ← زبان سایت: فارسی». قالب حتی بدون بستهٔ فارسی هم راست‌چین نمایش داده می‌شود.
3. **پیوندهای یکتا**: «نام نوشته» (`/%postname%/`).
4. **محتوای پایه**: «شهرداری بشرویه ← درون‌ریزی محتوای پایه» یا `wp bmn demo`. ایجاد می‌شود: ۸ دسته و ۳۸ خدمت، ۱۲ جاذبه، محله‌ها با برنامهٔ پسماند، برگه‌های خدمات (پیشخوان، ۱۳۷، پیگیری، عوارض، متوفیان، نوبت، انتقاد)، نمونهٔ اطلاعیه/خبر/مناقصه/رویداد (با برچسب «نمونه»).
5. **تنظیمات شهرداری**: تلفن، نشانی، ساعات کاری، مختصات ساختمان، شبکه‌های اجتماعی، پیوند اپ در بازار/مایکت.
6. **خدمات الکترونیک**:
   - پیامک: کاوه‌نگار (API Key + نام الگوی verify با توکن کد) یا SMS.ir (API Key + شناسهٔ قالب با پارامتر `CODE`).
   - درگاه: زرین‌پال (Merchant ID) یا سامان (شمارهٔ ترمینال). تا پیش از آماده‌شدن، «آزمایشی» می‌ماند و در رسید اعلام می‌شود.
   - ایمیل اطلاع‌رسانی درخواست‌های جدید.
7. **کارکنان**: نقش «کارمند شهرداری» فقط به منوی «درخواست‌ها / ۱۳۷» و پرداخت‌ها دسترسی دارد. تغییر وضعیت درخواست با یادداشت، به‌صورت خودکار برای شهروند پیامک می‌شود.
8. **منو**: منوی اصلی پیش‌فرض در سربرگ تعریف شده؛ از «نمایش ← ویرایشگر ← الگوها ← سربرگ» قابل ویرایش است.
9. **اتصال سامانهٔ درآمد** (عوارض واقعی):
   ```php
   add_filter( 'bmn_dues_provider', function () {
       return new class implements BMN_Dues_Provider {
           public function inquiry( $type, $identifier, $user_id ) {
               // فراخوانی وب‌سرویس سامانهٔ درآمد و بازگرداندن:
               return array( 'title' => '...', 'subtitle' => '...', 'items' => array( array( 'عوارض نوسازی', 850000 ) ), 'discount' => 0, 'total' => 850000 );
           }
       };
   } );
   ```
10. **اپ**: `app/README.md`؛ نشانی API را با `--dart-define=API_BASE=` بدهید.

## انتقال از سایت فعلی
برون‌بری اخبار و برگه‌ها (ابزارها ← برون‌بری)، درون‌ریزی در سایت جدید، و تعریف تغییرمسیر ۳۰۱ نشانی‌های قدیمی (افزونهٔ Redirection یا Rank Math) برای حفظ رتبهٔ گوگل.
