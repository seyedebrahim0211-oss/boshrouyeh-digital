# کارکنان، واحدها، بازدید شهردار و ناوگان

## نقش‌ها و دسترسی‌ها

| نقش | می‌بیند / انجام می‌دهد |
|---|---|
| شهردار (`bmn_mayor`) | همه‌چیز: درخواست‌های همهٔ واحدها، ارجاع، بازدید و دستورها، پرداخت‌ها، محتوا، ناوگان، گزارش حراست |
| معاون شهردار (`bmn_deputy`) | درخواست‌های همهٔ واحدها، ارجاع، ثبت و ویرایش کامل دستورها، پرداخت‌ها، ناوگان |
| روابط عمومی (`bmn_pr`) | اخبار، برگه‌ها، اطلاعیه‌ها، رویدادها، گزارش بازدیدها، دیدگاه‌ها |
| حراست و بازرسی (`bmn_security`) | گزارش حراست (ورودها، ورود ناموفق، تغییر نقش، ارجاع، انتشار، حذف، خروجی مالی) + فقط «شکایت از عملکرد» |
| امور مالی و درآمد (`bmn_finance`) | فهرست پرداخت‌ها و خروجی CSV |
| کارشناس میز خدمت / ۱۳۷ (`bmn_dispatcher`) | همهٔ درخواست‌ها (جز شکایات) و ارجاع به واحدها |
| مدیر واحد (`bmn_unit_head`) | درخواست‌ها و دستورهای **واحد خودش** + ارجاع |
| کارشناس واحد (`bmn_staff`) | درخواست‌ها و دستورهای **واحد خودش**؛ در دستورها فقط وضعیت/پیشرفت/گزارش اقدام |
| مسئول حمل‌ونقل (`bmn_transport`) | خطوط، خودروها و ردیاب‌ها + درخواست‌های واحد خودش |

واحد هر کارمند در «کاربران ← ویرایش ← واحد سازمانی» تعیین می‌شود. همه با «میز کار» (منوی بالای پیشخوان) شروع می‌کنند.

## ارجاع گزارش شهروند
- گزارش ۱۳۷ بر اساس موضوع خودکار به واحد مربوط می‌رود (روشنایی/پسماند ← خدمات شهری، آسفالت/آب‌گرفتگی ← عمران، فضای سبز، سد معبر ← اجرائیات، سایر ← میز خدمت). نوبت ملاقات ← دفتر شهردار، انتقاد/پیشنهاد ← روابط عمومی، شکایت ← حراست.
- تغییر «واحد مسئول» در صفحهٔ درخواست = ارجاع؛ در سابقه و پیگیری شهروند «ارجاع به …» دیده می‌شود و (اختیاری) پیامک می‌شود.

## بازدید شهردار و پروندهٔ پیگیری
۱. «بازدید شهردار ← ثبت بازدید»: تاریخ شمسی، محل، محله، گزارش و عکس.
۲. در همان صفحه «+ افزودن دستور»: **مسئلهٔ دقیق، دستور مشخص، واحد مسئول، مهلت اجرا، منبع اعتبار، وضعیت فعلی**.
۳. واحد مسئول وضعیت و درصد پیشرفت و «گزارش اقدام» را ثبت می‌کند؛ هر تغییر در سابقه می‌ماند و عمومی منتشر می‌شود.
۴. دستور با مهلت گذشته خودکار «با تأخیر» نمایش داده می‌شود. هر دستور کد پیگیری ۶ رقمی دارد.
- عمومی: `/mayor-visits/`، تابلوی شفافیت `/directives/` (شورت‌کد `[bmn_directives]`)، API: `/bmn/v1/visits`، `/bmn/v1/directives`، `/bmn/v1/directives/stats`.

## مینی‌بوس آنلاین (GPS)
۱. «ناوگان مینی‌بوس ← افزودن خط»: ایستگاه‌ها به ترتیب، هر خط `نام|عرض|طول`.
۲. «خودروها و ردیاب‌ها ← افزودن خودرو»: خط و پلاک؛ با ذخیره «شناسهٔ دستگاه» یک‌بار نمایش داده می‌شود.
۳. اتصال یکی از این راه‌ها:
   - گوشی اندرویدی داخل خودرو با اپ **Traccar Client**: Device identifier = شناسه، Server URL = `https://varsin-bsh.ir/wp-json/bmn/v1/fleet/osmand`، فاصلهٔ ارسال ۱۰ ثانیه.
   - ردیاب سخت‌افزاری (GT06، Teltonika، …) ← سرور Traccar ← forward به
     `…/fleet/osmand?id=<شناسه>&lat={latitude}&lon={longitude}&speed={speed}&bearing={course}&timestamp={fixTime}`
   - سامانهٔ اختصاصی: `POST …/fleet/ping` با هدر `X-Device-Key` و JSON `{"lat","lng","speed","heading"}`.
- شهروند: صفحهٔ `/minibus/` و اپ (خانه ← مینی‌بوس آنلاین): موقعیت، ایستگاه فعلی/بعدی و زمان تقریبی رسیدن.
