# اپ «بشرویهٔ من»

اپ شهروندی شهرداری بشرویه با Flutter؛ متصل به REST API افزونه‌های Boshrouyeh Core و E-Services.

## امکانات
اسپلش با نشان، خانه (میانبر خدمات، اطلاعیهٔ فوری، اخبار)، بانک ۳۸ خدمت با جست‌وجو و فیلتر، صفحهٔ استاندارد هر خدمت، استعلام و پرداخت عوارض (درگاه بانکی + بررسی خودکار نتیجه پس از بازگشت)، گزارش ۱۳۷ با عکس و موقعیت روی نقشه، پیگیری با کد، گردشگری با راهنمای صوتی و مسیریابی، محلهٔ من (زمان‌بندی پسماند، اعلان‌ها، رویدادها)، پیشخوان شهروند، ورود با کد پیامکی (JWT + refresh)، حالت شب کویر، کش آفلاین.

## اجرا
```bash
flutter pub get
./tool/setup_platforms.sh          # ساخت پوشه‌های android/ios و افزودن مجوزها
flutter run --dart-define=API_BASE=https://YOUR-SITE/wp-json/bmn/v1/
```
ساخت نسخهٔ انتشار: `flutter build apk --release --dart-define=API_BASE=...`

برای تست محلی با وردپرس روی سیستم: `--dart-define=API_BASE=http://10.0.2.2:8088/wp-json/bmn/v1/` (شبیه‌ساز اندروید).

## تست
`flutter test` — تبدیل تاریخ شمسی، اعداد فارسی، مدل‌ها و ویجت‌های برند.

آیکن‌ها از `lib/core/khesht_icons_data.dart` می‌آیند که با `php bin/sync-icons.php` از مجموعهٔ آیکن قالب تولید می‌شود.
